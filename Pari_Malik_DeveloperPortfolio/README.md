## 📩 Contact Form & Backend

The contact form is connected to a Node.js and Express.js backend.

### Working Flow

```text
Visitor
   ↓
Portfolio Contact Form
   ↓
Backend REST API
   ↓
Node.js + Express.js
   ↓
MongoDB Atlas
   ↓
Message Stored in Database
```

The backend API handles contact form submissions and stores the submitted information in MongoDB Atlas.

## ⚙️ How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/pari-art13/pari-art13.git
```

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Install Backend Dependencies

Navigate to the backend folder:

```bash
cd backend
```

Install the required dependencies:

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend folder and add the required MongoDB connection string.

Example:

```env
MONGODB_URI=your_mongodb_connection_string
PORT=5000
```

Do not share or upload the actual MongoDB connection string publicly.

### 5. Start the Backend

```bash
node server.js
```

The backend will run locally on:

```text
http://localhost:5000
```

### 6. Open the Portfolio

Open the frontend `index.html` file in a browser or use a local development server.
